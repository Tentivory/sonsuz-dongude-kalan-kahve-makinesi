# Sonsuz Döngüde Kalan Kahve Makinesi Simülatörü

## Giriş

Bu proje, insanlığın en büyük sorunlarından birine çözüm üretmek amacıyla başlatılmıştır: **Kahve neden hiç bitmiyor?**

Yıllar süren (asılında 3 dakika süren) ar-ge çalışmaları sonucunda, dünyanın ilk ve tek **Sonsuz Döngü Kahve Demleme Motoru** geliştirilmiştir. Bu motor, kahveyi demlemeye başlar ve asla bitirmez. Neden mi? Çünkü kahve bittiğinde hayatın anlamı sorgulanır ve biz buna izin vermeyiz.

## Özellikler

- %100 gerçek zamanlı demleme simülasyonu
- Rastgele bahaneler üretme algoritması ("filtre tıkandı", "su çok sıcak", "kahve çekirdekleri düşünüyor")
- Asla bitmeyen bir döngü (bu bir bug değil, özelliktir)
- Bilimsel olarak kanıtlanmış (kanıt: kendim denedim)

## Kullanım

```bash
python kahve_makinesi.py
```

**Uyarı:** Bu programı çalıştırdıktan sonra bilgisayarınız sonsuza kadar kahve demlemeye çalışabilir. Ctrl+C ile kurtulabilirsiniz ama kahve sizi takip eder.

## Bilimsel Temel

Schrödinger'in Kahvesi prensibine dayanır: Kahve hem demlenmiş hem demlenmemiş olabilir, ama biz sürekli demleniyor durumunda tutuyoruz. Bu, kuantum fiziğinin ta kendisidir.
